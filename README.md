# Mission 1 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the Linux environment, cloud-based workspaces, and professional documentation practices used by cloud engineers. The activity was completed using the KillerCoda Ubuntu environment and a GitHub portfolio repository.

## Objectives

- Access a cloud-based Linux environment
- Navigate the Linux file system
- Gather basic system information
- Organize files and directories using Linux commands
- Create a professional GitHub repository
- Document technical work using Markdown

## Activities Performed

1. Launched Ubuntu 24.04 in KillerCoda.
2. Created a new Linux user named **jsoriano**.
3. Logged in to the new user account.
4. Collected system information including distribution, kernel version, CPU, memory, and disk space.
5. Created a workspace directory structure.
6. Created the **about-me.md** file.
7. Created the **system-information.md** file.
8. Created the **reflection.md** file.
9. Created the GitHub repository **CCM101-jsoriano**.
10. Uploaded screenshots and organized all files in the required structure.
